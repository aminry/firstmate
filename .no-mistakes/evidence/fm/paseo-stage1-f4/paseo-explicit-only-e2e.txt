
===============================================================
1. AUTO-DETECTION REMOVED  (same ambient environment, before vs after)
===============================================================
Paseo exports PASEO_AGENT_ID into every descendant process, so an inherited
marker must not be read as the captain's consent to use the paseo backend.

$ PASEO_AGENT_ID=agent-uuid fm_backend_detect      # BEFORE (commit 9aa6940)
detected=<paseo> exit=0

$ PASEO_AGENT_ID=agent-uuid fm_backend_detect      # AFTER  (this change)
detected=<> exit=1

===============================================================
2. AMBIENT MARKERS NEVER ROUTE A REAL SPAWN THROUGH PASEO
===============================================================
Same fm-spawn command, PASEO_AGENT_ID + PASEO_TERMINAL_ID inherited, no
explicit backend anywhere. The backend boundary is crossed without paseo
being selected - the run stops later, on an unrelated missing-home check.

$ PASEO_AGENT_ID=... PASEO_TERMINAL_ID=... fm-spawn.sh sm-demo --secondmate
error: no firstmate home supplied or registered for sm-demo
exit=1
